# Cadeado-Terminal-Simples
Um simulador de cadeado desenvolvido em Python para terminal, com senha numérica, movimentação por teclado e sistema de alteração de senha

## Controles

- **W** — muda para a próxima linha
- **S** — volta para a linha anterior
- **A** — diminui o número
- **D** — aumenta o número
- **E** — abre/fecha o cadeado

## Sistema de chave

O projeto possui um sistema de chave utilizado no código para controlar o funcionamento do cadeado, mas ele ainda não é aprofundado nesta versão.
